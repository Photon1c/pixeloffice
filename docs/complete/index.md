# docs/complete index

This index organizes completed markdown documents in `docs/complete/`.

Use this as the first stop when locating historical specs, handoffs, implementation logs, and completion summaries.

## How to use this index

- Start with **Milestones and high-level summaries** for broad project context.
- Use **OpenCode and agent workflow specs** for agent/tooling behavior.
- Use **SCRUM, GitHub, and governance phases** for process/integration changes.
- Use **GUI, layout, and visual polish** for frontend/office-rendering work.
- Use **Fixes, debugging, and verification** for incident history and regressions.
