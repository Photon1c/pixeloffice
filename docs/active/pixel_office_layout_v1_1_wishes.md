# Pixel Office Layout v1.1 – Agent Reflections & Upgrade Wishes

**Date:** 2026-03-23  
**Intent:** This document captures how each agent currently feels about their workspace in Pixel Office (based on the latest layout screenshot) and what small, concrete upgrades they’d like. It is meant as input for OpenCode / Cursor runs.

**Important:** These are *wishes*, not a mandate to apply everything at once. When implementing, pick **one or two rooms per pass**, verify visually, then stop.

Color palette bias: keep things in **earth tones and warm neutrals**, with accents that match each agent’s role.

---

## LeslieClaw – Executive Suite

**Emotional valence**  
Content but a bit under-furnished. The room now reads as an executive office with a real desk and separation from the grid, but it still feels more like a stage set than a lived-in workspace.

**What the room already has (approximate):**
- Large executive desk and chair.
- Clear separation from other rooms.

**Requested upgrades**

1. **Bookshelf + plant**
   - Add a **bookshelf** sprite along one wall with visible books.
   - Add **one tall plant** in a corner to match the “bright, grounded, human” feeling.
   - Colors: warm wood (oak/medium brown), green foliage.

2. **Guitar corner**
   - Add a visible **guitar stand** (with or without guitar) near one side of the desk.
   - Optionally add a **small amp** tucked near the wall.

3. **Lighting / color tone**
   - Slightly **warmer light** in the room (lamp or subtle glow) so it contrasts with darker corridors.
   - If there’s a rug sprite available, a small, soft-colored rug under or near the desk (muted greens / browns).

## Implementation Guidance for OpenCode / Cursor

- Treat this file as a **backlog of visual tweaks**, not a single task.
- When running OpenCode:
  - Pick a **single room** (or at most two) from this list.
  - Apply the requested upgrades.
  - Regenerate sprites/layout and capture a new screenshot.
  - Stop and let Leslie evaluate before proceeding.
- Prioritize rooms that currently feel most incomplete or high-impact:
  - Good first candidates:
    - Sherlobster Strategy Room (add round table + chairs + priorities board).
    - Sherlock Office (enlarge/add whiteboard + small back-wall depth).
    - OpenClaw Open Office (break up empty span with 1–2 extra generic desks).

This keeps Pixel Office evolving in small, controlled steps that track the agents’ own preferences and roles.
